# Architecture

The interface and product flow live in React/TypeScript. Rust is a thin local native layer inside the Tauri process; there is no AIDOO server and no separate backend to operate.

`AppSettings` is the persisted product contract. It is normalized whenever it is loaded or saved. The API key is deliberately excluded and lives in macOS Keychain under service `app.aidoo.whisper-lite`. `storage.rs` owns atomic JSON writes, a bounded 10-item history, diagnostics redaction and failed-recording recovery. Private JSON reads are size-bounded; malformed or oversized settings, history and recovery metadata are atomically preserved as permission-restricted `.corrupt-…` files before safe defaults or audio-based recovery are used.

The recording state machine is:

`idle → starting → recording → transcribing → done/error → idle`

The keyboard-only native shortcut listener begins recording on key-down and requests transcription on key-up. A generation-bound five-minute watchdog stops and transcribes an unchanged active recording if key-up is lost; it cannot stop a later recording. Recording produces a temporary mono WAV. The app converts it to FLAC before upload. Temporary audio is permissioned for the current user only; partial FLAC output is removed after a conversion failure, and exact app-owned UUID temporary files left by a crash are removed after 24 hours. Recovery and user-selected output files are never part of that cleanup. A transcription failure moves the available WAV or FLAC audio to Recovery before reporting the error. Recovery filenames encode whether another API request is safe. If the metadata file is absent, corrupt or could not be written, startup finds the newest exact app-owned Recovery audio file and recreates its visible state. Unknown legacy files are conservatively non-retryable to avoid a duplicate API charge. A retry converts a retained WAV to a temporary FLAC while preserving the original until the whole operation succeeds. A successful result is copied to the clipboard first, then optionally written as FLAC/TXT and committed to history, and finally optionally pasted. If local persistence fails after OpenAI has returned text, every file already created remains in the selected folder and the recovery audio becomes non-retryable so the UI cannot cause a duplicate API charge.

The overlay receives state snapshots, progress events and user notices. It never owns recording state. Native events update it immediately, while a bounded authoritative snapshot poll repairs events missed when macOS wakes or resumes the hidden WebView; the poll runs quickly only during an active state and drops to a five-second idle interval. The overlay is centered in the active display's macOS work area, just above the Dock, and grows vertically so long status and error text can wrap. Status and errors are exposed as restrained VoiceOver live regions without announcing every upload-percentage change. Onboarding and deletion dialogs trap keyboard focus, support Escape and restore the previous focus when closed. Readiness requires completed onboarding, an available Keychain key, at least one microphone, Accessibility and no retained failed recording; the main window refreshes this system state when it regains focus. Closing the main window hides it while the tray and global shortcut remain active. A retained failed recording keeps the menu bar in its action-required state until retry or deletion resolves it. A failed automatic paste keeps the exact clipboard fallback available as the menu bar's last error after its toast disappears. A macOS Reopen event restores the main window from the Dock; Quit remains explicit in the menu bar and is blocked while a native operation owns recording, transcription, key validation, microphone probing or shortcut capture so unfinished user work cannot be discarded.

Microphone routing follows the selected device, then the current system default, then the remaining available inputs when automatic fallback is enabled. A non-primary input is reported as a fallback even when automatic system-default selection is used. With fallback disabled, only the selected device is attempted. Calls into the dedicated audio worker have a 30-second deadline: a timed-out start queues an unconditional stop, and a late completed capture removes its temporary WAV automatically when no caller receives it. API-key validation, microphone tests and history/recovery deletion share the native operation lock with recording and transcription. Settings and onboarding controls disable while dictation is active, and settings or shortcut-capture mutations are also rejected by the native operation lock.

The WebView CSP permits only local IPC; OpenAI communication is implemented in native code and targets `api.openai.com`. Tauri capabilities and application commands are split per window: the main window alone can use settings, recording, local files, Launch at Login and the two allowlisted support/API-key URLs. The overlay can only read its reduced bootstrap state and current recording state, listen for native events, resize itself and request native repositioning; its bootstrap payload contains no history, API-key status, microphone inventory or local paths. API validation uses `GET /v1/models`; an authentication failure is rejected, while an authenticated `403 Forbidden` is accepted so an endpoint-restricted key that can transcribe does not fail onboarding merely because it cannot list models. Transcription uses `POST /v1/audio/transcriptions`. Audio is streamed from disk into the request and network calls have bounded connection and total timeouts. Incoming transcription JSON is limited to two megabytes; API error bodies are limited to 64 kilobytes and their displayed message is normalized to 500 characters. No analytics or background telemetry exists. A user-requested diagnostic ZIP contains sanitized app logs, settings without the API key or local device paths, basic system/version data and up to three relevant Apple crash reports. OpenAI-style keys, the home-directory path and transcript text known to the local history are redacted from included text. The ZIP is written to a private temporary file, synchronized and atomically published only when complete; Quit remains blocked during creation. The package remains local until the user chooses to share it.

Releases contain a notarized and stapled DMG plus its SHA-256 checksum. New versions are published on the AIDOO website and installed manually; the application has no updater endpoint or background version check.

The macOS bundle uses English as its base `Info.plist` language and ships `en.lproj` and `bg.lproj` `InfoPlist.strings` resources. This keeps the system Microphone permission explanation aligned with the user's macOS language before the WebView interface is available.
